# Привычка

**Большая цель → маленькие шаги → ежедневная привычка.** Отдельное русскоязычное веб-приложение, не зависящее от To-Do.

## Возможности

- Создание и редактирование целей, привычек и небольших шагов; готовые шаблоны Python, язык, спорт.
- Привязка привычки к конкретному триггеру: «После … я …».
- Один ежедневный чек-ин на привычку, переход к следующему незавершённому шагу, отмена отметки.
- Самостоятельная отметка отдельных шагов и достижение цели; ежедневная привычка продолжается и после закрытия всех шагов.
- Статистика по дням и календарь, текущая/лучшая серия, достижения 3/7/30 дней действий. Пропуск не удаляет историю.
- Автономное локальное хранение (localStorage) и JSON экспорт/импорт с проверкой. Никаких аналитических SDK, регистрации или серверного хранения.
- Выбор одного из двух оригинальных героев (Пуши или Бубо), возможность поменять героя в шапке, приветствия и поздравления. Можно продолжить без героя.
- Выбор сохраняется вместе с целями и входит в экспорт JSON; старые резервные копии по-прежнему импортируются.
- Мобильный интерфейс, а11y-подсказки и reduced-motion.

Два героя — Пуши и Бубо — доступны на экране выбора. Обе иллюстрации находятся локально в `assets/companions/*.webp` (мобильные файлы WebP); герой меняется без удаления целей. Режим без героя также доступен. Новые герои не продаются и не требуют регистрации.

## Запуск

Это статический сайт, сборка не нужна. Для проверки ES-модулей откройте локальный HTTP-сервер:

```bash
python3 -m http.server 8080
```

Перейдите на `http://localhost:8080`. Тесты бизнес-логики: `npm test` (Node.js 20+).

## Публикация GitHub Pages

Сайт опубликован по адресу **https://safal207.github.io/privichka/**. Изменения в ветке `main` автоматически запускают `.github/workflows/deploy.yml`: workflow готовит статические файлы, дожидается индексации артефакта и публикует их в GitHub Pages. История и результат публикаций — во вкладке **Actions → Publish Privichka to GitHub Pages**. Источник публикации в **Settings → Pages → Build and deployment** должен быть **GitHub Actions**. Путь к ресурсам относительный и совместим с GitHub Pages.

## Границы MVP

Прогресс хранится на конкретном устройстве в выбранном браузере. Удаление данных браузера удалит историю, если нет экспортированной копии. Пуш-уведомления, синхронизация между устройствами и AI-разбиение ещё не реализованы. Встроенные шаблоны не требуют API. Ручное QA-тестирование в нескольких браузерах рекомендуется перед публичным запуском.
